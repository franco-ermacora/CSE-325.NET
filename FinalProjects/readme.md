## Project Ideas Under Consideration

### Option 1: Media Vault (Personal Books & Movies Tracker)
- Summary & Features: A clean personal tracking application where users register and manage their watchlist/library. Features include adding items with details (Title, Author/Director, Status: Pending/Completed, Rating 1-5), updating status after viewing, and filtering the collection.
- Target Audience: Book and movie enthusiasts looking for a simple, distraction-free log of media consumed.

### Option 2: Habit Tracker Lite
- Summary & Features: A daily routine and habit management application. Features include adding custom daily habits, marking completion status for the current day, viewing historical progress, and managing habit categories.
- Target Audience: Individuals seeking a straightforward tool to build and track daily habits.

### Option 3: Travel Planner Lite
- Summary & Features: A trip planning dashboard. Features include creating trip entries (Destination, Dates, Budget), linking packing/todo checklists to each trip, updating costs, and deleting past/canceled trips.
- Target Audience: Casual travelers who need a lightweight tool to organize trip details.
